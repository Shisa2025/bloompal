# BloomPal

BloomPal is a gamified hand rehabilitation platform developed for the Huawei Tech4City Competition 2026.

The project combines interactive rehabilitation activities with an administrative dashboard for monitoring user activity, rehabilitation sessions, and progress.

BloomPal was selected as one of 14 semi-finalist teams from 240 submissions across Singapore.

## Overview

BloomPal explores how gamification can make prescribed hand rehabilitation activities more engaging while allowing rehabilitation activity and session data to be monitored through a central dashboard.

The prototype consists of:

- A patient-facing gamified rehabilitation environment
- Interactive hand-based activities
- Rehabilitation session tracking
- An administrative dashboard for monitoring activity and progress
- Reporting and analytics features

## Administrative Dashboard

The dashboard provides an overview of rehabilitation activity and sessions, including:

- Recent session activity
- Session duration
- Game activity metrics
- Left/right actions
- Attempt and success information
- User activity trends
- Users who may require follow-up
- Reports and CSV export
